# Marketing Social Media Analyzer

## Overview

A deployed NLP-powered dashboard for analyzing social media content in a marketing context. The tool processes social media posts and extracts actionable insights for marketing teams.

## Problem

Marketing teams generate and consume large volumes of social media content but lack automated tools to analyze sentiment, topics, and engagement patterns at scale.

## Solution

Built an end-to-end NLP pipeline that:
- Ingests social media data
- Applies sentiment analysis and topic modeling
- Surfaces results in an interactive dashboard

## Features

- Sentiment classification (positive / negative / neutral)
- Topic extraction and keyword analysis
- Trend visualization over time
- Dashboard interface for non-technical users

## Tech Stack

- Python (NLP pipeline)
- Hugging Face Transformers for NLP models
- Interactive dashboard (Streamlit or Plotly)

## Status

**Deployed.** Live and accessible.
