# PEPAdb — Client Data Platform

## Overview

PEPAdb is a data management platform built for a research group at the University of Sevilla. It provides a structured interface for storing, querying, and managing client and research data.

## Role

Developer. Designed and built the platform from requirements gathered directly from the research group.

## Problem

The research group needed a centralized, structured platform to manage their client data — replacing ad-hoc spreadsheets and disconnected tools with a proper database-backed system.

## Solution

Built a client data platform with:
- A relational database backend for structured client records
- A query interface for filtering and retrieving records
- Data ingestion workflows for importing existing records
- Basic reporting and export functionality

## Tech Stack

- Python (backend logic)
- SQL (relational database design and queries)

## Status

Delivered and in use by the University of Sevilla research group.
