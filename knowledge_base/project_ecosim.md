# EcoSim RL — Ecological Simulation with Reinforcement Learning

## Overview

EcoSim is a reinforcement learning project developed as Alejandro's BSc thesis at Leiden University. It involves building a simulation environment for ecological systems and training RL agents to optimize outcomes within that environment.

## Research Question

How can reinforcement learning agents learn effective policies for managing ecological systems, where actions have delayed and interdependent consequences?

## Approach

- Designed a custom simulation environment modelling ecological dynamics
- Implemented RL agents using policy gradient or value-based methods
- Trained agents to maximize a long-term ecological objective (e.g., biodiversity, resource sustainability)
- Evaluated agent performance across different environment configurations

## Key Concepts

- Custom Gym-compatible environment design
- Reward shaping for ecological objectives
- Agent training stability and convergence analysis

## Tech Stack

- Python
- PyTorch (neural network policy)
- OpenAI Gym / custom environment
- NumPy for simulation logic

## Status

**BSc thesis project** at Leiden University DS&AI programme.
